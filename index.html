Codex CLI 的核心代码是开源的，但一万多个提交不会自己解释自己。这个站不搬运教程， 而是把五条主干线路做成可以动手的仪器：单步走完一轮 Agent 循环，逐层搭出一次模型请求， 切换沙箱模式看权限判定，放一遍客户端协议报文，翻 135 个 crate 的分层图谱。

左边那排编号就是目录：00 总览，01–05 五条线路，06 术语速查。 正文里带 虚线下划线 的词， 悬停或点一下就能看到人话解释。
