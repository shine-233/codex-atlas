三原语：协议的全部词汇量

      

        
原语定义与生命周期

        
          
Item输入/输出的基本单位。类型含用户消息、agent 消息、reasoning、命令执行、文件变更、审批请求、MCP 调用、网页搜索、todo、错误。生命周期固定为 started → delta → completed：started 到达即可渲染占位，delta 流式补全，completed 落定。

          
Turn由用户输入发起的一轮智能体工作。从提交输入开始，到产出结束；包含过程中产生的全部 items——中间步骤和产物都在里面。

          
Thread会话的持久容器。可创建、恢复（resume）、分叉（fork）、归档（archive）。事件历史持久化保存，客户端断线重连后能恢复出一致的时间线。

        
      

      

        接入面不止一条：stdio JSONL 是主通道，streaming HTTP 备选；
        codex app-server generate-ts 能直接从 Rust 协议生成 TypeScript 定义，
        官方客户端已覆盖 Go / Python / TS / Swift / Kotlin。TUI 正在重构为标准子进程客户端——和其他界面同等待遇。
